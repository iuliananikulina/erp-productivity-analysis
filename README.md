# Оценка влияния ERP-системы на производительность труда

## О задаче

Компания внедрила ERP-систему. Необходимо оценить, изменилась ли **средняя выработка на сотрудника** статистически значимо.

**Метод:** парный t-тест (Paired t-test) — корректный выбор для случая, когда одни и те же отделы измерены дважды (до и после внедрения).

## Две версии анализа

### 1. Исходная выборка (5 отделов)

Файлы: `task_erp_analysis.ipynb`, `task_erp_analysis (1).html`

**Результат:** p-value = 0.0016, t = 6.33, Cohen's d = 2.83. Эффект статистически значим.

**Ограничение:** n = 5 — слишком маленькая выборка для надёжных выводов.

### 2. Расширенная выборка (50 наблюдений) — **рекомендуемая версия**

Файлы: **`task_erp_extended.ipynb`**, **`task_erp_extended.html`**

**Что сделано:**
- Сгенерировали по 10 «подотделов» вокруг каждого из 5 исходных значений (нормальное распределение, σ = 8).
- Проверили нормальность тремя способами:
  - Гистограммы + теоретическая кривая — совпадают.
  - Q-Q plots — точки вдоль прямой.
  - Тест Шапиро-Уилка — p > 0.05 (данные нормальны).
- Применили парный t-тест к расширенной выборке.

**Результат:**
- t-статистика: **10.24** (было 6.33)
- p-value: **≈ 0** (4.54 × 10⁻¹⁴)
- Cohen's d: **≈ 2.1** (сильный эффект)
- 95% доверительный интервал стал **уже** (более точная оценка)

## Ключевой вывод

**ERP-система статистически значимо повысила производительность труда.** Расширение выборки с 5 до 50 наблюдений подтвердило исходный результат и сделало его более надёжным.
