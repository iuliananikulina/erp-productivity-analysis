# Оценка влияния ERP-системы на производительность труда

## О задаче

Компания внедрила ERP-систему. Необходимо оценить, изменилась ли **средняя выработка на сотрудника** статистически значимо.

**Метод:** парный t-тест (Paired t-test) — корректный выбор для случая, когда одни и те же 5 отделов измерены дважды (до и после внедрения).

## Исходные данные

| Отдел | До внедрения | После внедрения | Разница |
|---|---|---|---|
| A | 120 | 145 | +25 |
| B | 135 | 155 | +20 |
| C | 110 | 140 | +30 |
| D | 150 | 160 | +10 |
| E | 130 | 150 | +20 |

## Ключевые результаты

| Показатель | Значение |
|---|---|
| Средняя выработка ДО | 129.0 тыс. руб./чел. |
| Средняя выработка ПОСЛЕ | 150.0 тыс. руб./чел. |
| Средняя разница | **+21.0 тыс. руб./чел.** (+16.3%) |
| t-статистика | **6.33** |
| p-value | **0.0016** |
| 95% доверительный интервал | **[11.79; 30.21]** |
| Cohen's d (размер эффекта) | **2.83** (очень сильный) |

## Вывод

**p-value = 0.0016 < 0.05** — мы отклоняем нулевую гипотезу. Разница статистически значима: **ERP-система повысила производительность труда** в среднем на 21 тыс. руб./чел.
